# CLIProxyAPI + OpenCode + Antigravity Config

Готовая конфигурация для настройки безлимитного подключения моделей **Gemini 3.6 Flash** к **OpenCode** через **CLIProxyAPI** и аккаунты **Antigravity**.

---

## 📁 Содержимое папки:

1. **`config.yaml`** — Настроенный файл конфигурации CLIProxyAPI:
   - Включена локальная веб-панель управления (`secret-key: 'root'`).
   - Настроена замена уровня мышления (Thinking mode) для OpenCode.
   - Поставлены оптимизированные таймауты TTFT (20-25 сек) и автоматический ретрай.
2. **`opencode.json`** — Конфиг для OpenCode:
   - Подключен локальный провайдер CLIProxyAPI.
   - Подключена инструкция промпта через относительный путь `"./promt.md"`.
   - Запрещен вызов обычного `grep` (`"permission": { "grep": "deny" }`).
3. **`promt.md`** — Файл с кастомными инструкциями для OpenCode (использование `rg` вместо `grep`, параллельные вызовы и русский язык).
4. **`Панель управления.url`** — Прямой ярлык для перехода в веб-панель управления (`http://localhost:8317/management.html`).

---

## 🚀 Как использовать:

1. Поместите **`config.yaml`** и ярлык **`Панель управления.url`** в папку с установленным **CLIProxyAPI**.
2. Поместите файлы **`opencode.json`** и **`promt.md`** **вместе** в вашу глобальную папку конфигурации OpenCode (на Windows это `C:\Users\<ВашПользователь>\.config\opencode\`).
3. В **`opencode.json`** прописан относительный путь `"./promt.md"`, поэтому промпт подтянется автоматически, если оба файла находятся в одной папке!
